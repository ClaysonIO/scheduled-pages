Scheduled Pages

Automatically open web pages at scheduled times

Scheduled Pages is a web application that lets you create schedules using cron expressions to automatically open web pages at specific times. Perfect for reminders, educational resources, meeting links, or any web content you want to appear at just the right moment.

The application runs entirely in your browser with no server required. All schedules are stored locally using IndexedDB.

Saturday Morning Cartoons

This application was created when I wanted a way to automatically turn on random cartoons for my small children on Saturday mornings. Now they can wake up to their favorite shows starting automatically at the scheduled time!

Launch Application View on GitHub

Key Features

  • Schedule web pages using cron expressions
  • Add multiple URLs to each schedule - a random one will be opened
  • View a countdown to the next scheduled page opening
  • All data stored locally in your browser
  • No server required - runs entirely in the browser

Use Cases

  • Daily reminders by scheduling important websites
  • Educational resources on a rotating schedule
  • Automatically open meeting links at scheduled times
  • Digital signage system rotating through web pages
  • Saturday morning cartoons for kids
